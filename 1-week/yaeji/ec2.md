## EC2 인스턴스 개요

AWS EC2는 가상 서버를 제공하는 서비스로, 다양한 유형의 인스턴스를 선택할 수 있습니다.

### EC2 인스턴스 이름 규칙
`m5.2xlarge` 같은 형식으로 인스턴스를 구분합니다.
- `m` → Instance Class (범용)
- `5` → Instance Generation (세대, 최신 세대일수록 성능 향상됨)
- `2xlarge` → Size (CPU & Memory 크기 증가)

### EC2 인스턴스 유형

#### General Purpose (범용)
- t, m 계열
- 균형 잡힌 CPU, 메모리 성능 제공
- 예: 웹 애플리케이션, 마이크로서비스

#### Compute Optimized (C 계열)
- c 계열 (예: c6g, c5n)
- CPU 성능이 중요한 워크로드에 적합
- 예: 고성능 웹 서버, 머신러닝, 과학 계산

#### Memory Optimized (R 계열)
- r, x, z 계열
- 고성능 RAM을 제공하여 대규모 데이터 처리에 적합
- 예: 인메모리 데이터베이스, 데이터 분석

#### Storage Optimized
- i, g, h 계열
- 고속 I/O 성능이 필요한 데이터 처리에 적합
- 예: 분산 파일 시스템, OLTP 데이터베이스

더 많은 EC2 인스턴스 유형은 AWS 공식 문서에서 확인 가능

## EC2 보안 그룹: AWS 네트워크 방화벽

AWS **보안 그룹(Security Group)**은 EC2 인스턴스의 네트워크 트래픽을 제어하는 방화벽 역할을 합니다.

### 보안 그룹 특징
- 인스턴스와 1:1 관계가 아니다 (하나의 보안 그룹을 여러 인스턴스에 적용 가능)
- VPC 및 리전마다 설정이 다르다 (새로운 리전이나 VPC를 사용할 경우 새로운 보안 그룹을 생성해야 함)
- 다른 보안 그룹을 참조 가능 (예: DB 보안 그룹이 웹 서버 보안 그룹을 참조하여 내부 접근만 허용 가능)

### 주요 포트 번호

| 포트 | 프로토콜 | 용도 |
|------|---------|------|
| 22   | SSH     | 리눅스 인스턴스 접속 |
| 21   | FTP     | 파일 전송 |
| 80   | HTTP    | 일반 웹사이트 |
| 443  | HTTPS   | 보안 웹사이트 |
| 3389 | RDP     | Windows 원격 접속 |


## EC2 인스턴스 구매 옵션

### 1. On-Demand (온디맨드)
- 사용한 만큼 비용을 지불하는 방식 (가장 비쌈)
- 장점: 유연한 사용 가능
- 단점: 비용이 비쌈
- 적합한 경우: 짧은 워크로드

### 2. Reserved Instances (RI, 예약 인스턴스)
- 1년 또는 3년 약정으로 구매하여 최대 72% 비용 절감 가능
- 특정 인스턴스 속성을 예약하여 비용 절감
- 적합한 경우: 장기적으로 DB 또는 애플리케이션을 운영할 경우

### 3. Savings Plan
- 온디맨드보다 비용 절감 가능 (1년~3년 약정)
- 특정 사용량을 약정하여 비용 절감

### 4. Spot Instances
- 미사용 컴퓨팅 자원을 활용하여 저렴한 비용으로 인스턴스 운영 (최대 90% 할인)
- 단점: 신뢰성이 낮음 (AWS에서 자원이 필요하면 종료됨)
- 적합한 경우: 단기 워크로드, 비핵심 애플리케이션

### 5. Dedicated Hosts
- 물리적 서버를 완전히 예약하여 사용
- 특정 라이선스를 사용하는 경우 유용

### 6. Dedicated Instances
- 물리적 하드웨어를 공유하지 않음

### 7. Capacity Reservations
- 특정 가용 영역(AZ)의 EC2 인스턴스 용량을 예약 가능
