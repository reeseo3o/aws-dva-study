# AWS 컨테이너 서비스

## Docker란?

Docker는 애플리케이션과 모든 종속성을 하나의 독립된 단위로 패키징하는 컨테이너화 플랫폼입니다.

컨테이너에 앱이 패키징 된다 -> 컨테이너는 표준화 되어있어 어떤 운영체제에서든 사용 가능하다.



### 주요 구성 요소
- Docker 엔진: 컨테이너 관리 기술
- Docker 이미지: 애플리케이션 템플릿
- Docker 컨테이너: 실행 인스턴스
- Dockerfile: 이미지 생성 지시사항

### 이점
- 일관된 환경 제공
- 애플리케이션 격리
- 가상 머신보다 경량화
- 간편한 배포 및 확장


### 도커와 가상머신의 차이
도커도 가상화 기술을 기반하지만 리소스가 호스트와 공유되어 한 서버에서 다수의 컨테이너를 실행할 수 있다.

가상머신의 경우 인프라와 호스트 운영체제가 있고 그 위에 하이퍼바이저가 있고 그 다음에 앱과 게스트 운영체제가 있다 -> ec2가 정확히 이 원리입니다.

도커 컨테이너의 경우 ec2 인스턴스 같은 host os가 있고 도커 데몬 위에 컨테이너가 엄청 많은 구조.

영상에서 차이점을 이렇게 설명했지만 사실 두개의 큰 차이는 어디까지 가상화 하느냐 입니다.

가상 머신은 CPU/메모리, 하드디스크, OS, 커널 등을 모두 가상화해서 정말 독립적인 하나의 컴퓨터 머신을 구성하지만 (그래서 ec2가 딱 이 원리라는 것)
도커는 위에 언급한 모든 요소를 호스트의 것을 공유 받아서 씁니다. 그렇기에 매우 경량화 된거죠

## Amazon ECS (Elastic Container Service)

AWS의 완전 관리형 컨테이너 오케스트레이션 서비스입니다.

### 핵심 개념
- 클러스터: 컨테이너 실행 인프라 그룹
- 태스크 정의: 컨테이너 실행 청사진
- 태스크: 실행 중인 컨테이너 세트
- 서비스: 지정된 수의 태스크 유지

### 시작 유형
- EC2: 사용자가 EC2 인스턴스 관리
- Fargate: 서버리스 컨테이너 실행

### 주요 이점
- AWS 서비스 통합
- 자동 확장 지원
- 보안 기능 내장
- 비용 효율적 운영

## ECS 서비스 - 오토 스케일링

### 스케일링 유형
- 대상 추적: 특정 지표 목표값 유지
- 단계 스케일링: 임계값 기반 조정
- 예약 스케일링: 예측 가능한 패턴 대응

### 모범 사례
- 적절한 지표 선택
- 쿨다운 기간 설정
- 정기적인 부하 테스트

## Amazon ECS - 롤링 업데이트

다운타임 없이 점진적으로 애플리케이션을 업데이트하는 배포 전략입니다.

### 주요 구성 요소
- 최소 정상 비율: 배포 중 유지해야 할 최소 태스크 비율
- 최대 비율: 배포 중 허용되는 최대 태스크 비율

### 작동 방식
1. 새 태스크 시작
2. 정상 상태 확인
3. 이전 태스크 중단
4. 완료될 때까지 반복

## Amazon ECS - 솔루션 아키텍처

### 일반적인 패턴
- 웹 애플리케이션: ALB → ECS → 데이터베이스
- 마이크로서비스: API Gateway → 여러 ECS 서비스
- 백그라운드 처리: SQS → ECS 작업자
- CI/CD: 소스 → 빌드 → ECR → ECS

## Amazon ECS 태스크 정의 - 심화 학습

### 주요 고급 옵션
- 환경 변수 관리
- 리소스 제한 설정
- 로깅 구성
- 스토리지 옵션
- 네트워킹 설정

### 특별한 컨테이너 유형
- 사이드카 컨테이너
- 초기화 컨테이너
- 컨테이너 종속성 관리

## Amazon ECS - 태스크 배치

### 배치 전략
- binpack: 비용 최적화
- spread: 가용성 향상
- random: 무작위 배치

### Fargate 배치
- 서브넷 선택
- 플랫폼 버전 선택

## Amazon ECR (Elastic Container Registry)

안전하고 관리형 Docker 이미지 레지스트리 서비스입니다.

### 주요 기능
- IAM 통합 보안
- 이미지 취약점 스캔
- 자동 확장
- 라이프사이클 정책

### 기본 사용법
1. 인증
2. 이미지 태깅
3. 이미지 푸시/풀
4. ECS와 통합

## AWS Copilot - 개요

컨테이너화된 애플리케이션 개발과 배포를 단순화하는 CLI 도구입니다.

### 주요 특징
- 간소화된 워크플로
- 다양한 서비스 유형 지원
- 환경 관리 기능
- CI/CD 파이프라인 자동화

### 기본 워크플로
애플리케이션 생성 → 환경 설정 → 서비스 정의 → 배포

## Amazon EKS (Elastic Kubernetes Service)

AWS에서 Kubernetes를 실행하기 위한 관리형 서비스입니다.

### 주요 구성 요소
- 관리형 컨트롤 플레인
- 다양한 데이터 플레인 옵션
- 클러스터 네트워킹 지원

### 주요 이점
- Kubernetes 표준 호환성
- AWS 서비스 통합
- 강화된 보안
- 관리 복잡성 감소

### EKS vs ECS
- EKS: 표준 Kubernetes, 높은 이식성, 더 복잡함
- ECS: AWS 최적화, 더 간단한 관리, AWS 내 이식성
