## Linux 네트워크 관련 명령어 요약
그냥 정리해봤습니다 ㅎ

## 1. ping

*   **기능:** 대상 호스트(IP 주소 또는 도메인 이름)가 네트워크 상에서 응답하는지 확인합니다.
*   **사용 상황:** 특정 서버나 장치가 네트워크에 연결되어 있고 통신 가능한 상태인지 간단하게 테스트할 때 사용합니다.
*   **예시:** `ping google.com`

## 2. ss (Socket Statistics)

*   **기능:** 시스템의 네트워크 소켓 상태를 확인합니다. `netstat`보다 빠르고 상세한 정보를 제공하며 최신 리눅스 시스템에서 권장됩니다.
*   **사용 상황:** 현재 열려있는 포트, 특정 포트를 사용하는 프로세스, 네트워크 연결 상태 등을 확인할 때 사용합니다.
*   **주요 옵션:**
    *   `-t`: TCP 소켓 표시
    *   `-u`: UDP 소켓 표시
    *   `-l`: 리스닝(Listening) 상태의 소켓 표시
    *   `-n`: 호스트 이름이나 서비스 이름 대신 IP 주소와 포트 번호로 표시
    *   `-p`: 소켓을 사용 중인 프로세스 정보 표시
    *   `-a`: 모든 상태의 소켓 표시
*   **예시:** `ss -tulnp` (TCP/UDP 리스닝 포트를 프로세스 정보와 함께 숫자 형태로 표시)

## 3. netstat (Network Statistics)

*   **기능:** 네트워크 연결 상태, 라우팅 테이블, 인터페이스 통계, 열린 포트 등을 표시합니다. (구 버전 도구)
*   **사용 상황:** 구형 리눅스 시스템이나 Windows 환경에서 네트워크 상태를 확인할 때 사용합니다. (최신 리눅스에서는 `ss` 권장)
*   **주요 옵션:** `ss` 명령어와 유사한 옵션들을 사용합니다. (`-a`, `-l`, `-t`, `-u`, `-p`, `-n` 등)
*   **예시:** `netstat -tulnp`

## 4. dig (Domain Information Groper)

*   **기능:** DNS 서버에 질의하여 도메인 이름에 대한 다양한 정보(IP 주소, 메일 서버, 네임 서버 등)를 조회합니다.
*   **사용 상황:** DNS 설정 문제 해결, 특정 도메인의 DNS 레코드(A, MX, NS, TXT 등) 확인이 필요할 때 사용합니다.
*   **주요 옵션:**
    *   `+short`: 결과 간략하게 출력
    *   `@ [DNS 서버 IP]`: 특정 DNS 서버를 통해 조회
    *   `-x [IP 주소]`: IP 주소로 도메인 이름 역방향 조회
    *   `[레코드 타입]`: 조회할 DNS 레코드 타입 지정 (예: `MX`, `NS`)
*   **예시:**
    *   `dig google.com`
    *   `dig +short google.com`
    *   `dig @8.8.8.8 openai.com A`

## 5. nslookup (Name Server Lookup)

*   **기능:** 도메인 이름을 IP 주소로 변환하거나 그 반대의 작업을 수행합니다. (구 버전 도구이지만 여전히 많이 사용됨)
*   **사용 상황:** 간단하게 도메인 이름에 대한 IP 주소를 확인할 때 사용합니다.
*   **예시:** `nslookup openai.com`

## 6. curl (Client URL)

*   **기능:** 다양한 프로토콜(주로 HTTP, HTTPS, FTP 등)을 사용하여 데이터를 전송하거나 받아옵니다. 웹 서버와의 통신 테스트나 API 호출에 유용합니다.
*   **사용 상황:** 웹 서버 응답 확인, API 테스트, 파일 다운로드 등에 사용합니다.
*   **주요 옵션:**
    *   `-I`: HTTP 헤더 정보만 표시
    *   `-X [메소드]`: 사용할 HTTP 메소드 지정 (GET, POST 등)
    *   `-d [데이터]`: POST 요청 시 전송할 데이터 지정
    *   `-H [헤더]`: 사용자 정의 헤더 추가
*   **예시:**
    *   `curl http://localhost:3000`
    *   `curl -I https://openai.com`

## 7. wget (Web Get)

*   **기능:** 웹(HTTP, HTTPS, FTP)에서 파일을 다운로드합니다.
*   **사용 상황:** URL을 통해 파일을 직접 다운로드해야 할 때 사용합니다.
*   **주요 옵션:**
    *   `-O [파일명]`: 다운로드 받을 파일의 이름 지정
    *   `-c`: 이어받기 기능 활성화
*   **예시:** `wget https://example.com/file.zip`

## 8. traceroute

*   **기능:** 특정 목적지 호스트까지 패킷이 전달되는 네트워크 경로를 추적하여 보여줍니다. 각 구간(홉)에서의 지연 시간 등을 확인할 수 있습니다.
*   **사용 상황:** 네트워크 연결 문제 발생 시 어느 구간에서 병목 현상이나 문제가 발생하는지 진단할 때 사용합니다.
*   **예시:** `traceroute google.com`

## 9. nmap (Network Mapper)

*   **기능:** 대상 호스트 또는 네트워크의 포트 스캔, 운영체제 탐지, 서비스 버전 확인 등 다양한 네트워크 탐색 및 보안 감사를 수행합니다.
*   **사용 상황:** 서버에서 어떤 포트가 열려 있는지 확인하거나 네트워크 보안 상태를 점검할 때 사용합니다.
*   **주요 옵션:**
    *   `-p [포트 범위]`: 스캔할 포트 지정 (예: `-p 22,80,443`)
    *   `-sV`: 포트에서 실행 중인 서비스 버전 정보 확인
    *   `-O`: 운영체제 정보 탐지 시도
*   **예시:**
    *   `nmap 192.168.0.1`
    *   `nmap -p 22,80,443 192.168.0.5`

## 10. ip

*   **기능:** 네트워크 인터페이스 설정 및 정보 확인, 라우팅 테이블 관리 등 다양한 네트워크 관련 작업을 수행합니다. (`ifconfig` 대체 명령어)
*   **사용 상황:** 시스템의 IP 주소 확인, 네트워크 인터페이스 활성화/비활성화, 라우팅 경로 확인 및 설정 등에 사용합니다.
*   **주요 명령어 (서브 커맨드):**
    *   `ip address show` 또는 `ip a`: 모든 네트워크 인터페이스의 IP 주소 및 정보 표시
    *   `ip route show` 또는 `ip r`: 라우팅 테이블 표시
    *   `ip link show` 또는 `ip link`: 네트워크 인터페이스 목록 및 상태 표시
*   **예시:**
    *   `ip a`
    *   `ip r`
    *   `ip link`
